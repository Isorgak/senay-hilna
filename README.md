## 🚀 Getting Started

### 1. Clone or Download

```bash
# Clone the repository
git clone https://github.com/your-username/senay-hilna.git

# Or download as ZIP and extract
```

### 2. Open Locally

Simply open `index.html` in your web browser:

```bash
# On macOS
open index.html

# On Linux
xdg-open index.html

# On Windows
start index.html
```

Or use a local server (recommended):

```bash
# Using Python 3
python -m http.server 8000

# Using Node.js (npx)
npx serve

# Using PHP
php -S localhost:8000
```

Then visit: `http://localhost:8000`

## ✏️ Customization Guide

### Update Zoom Meeting Details

Edit `index.html` (around line 200):

```html
<span class="zoom-value" id="zoomLink">https://zoom.us/j/YOUR-MEETING-ID</span>
<span class="zoom-value" id="zoomId">YOUR-MEETING-ID</span>
<span class="zoom-value" id="zoomPass">YOUR-PASSWORD</span>
```

### Update Social Media Links

Edit the social links in `index.html` (around line 250):

```html
<a href="https://chat.whatsapp.com/YOUR-GROUP-LINK" target="_blank" class="social-card whatsapp">
<a href="https://t.me/YOUR-CHANNEL" target="_blank" class="social-card telegram">
<a href="https://facebook.com/YOUR-PAGE" target="_blank" class="social-card facebook">
<!-- etc. -->
```

### Update Contact Information

Edit contact details in `index.html` (around line 320):

```html
<p class="contact-value" id="phoneNum">+44 YOUR-PHONE-NUMBER</p>
<p class="contact-value" id="emailAddr">your-email@gmail.com</p>
```

### Update Mission Statement

Edit the mission text in `index.html` (around line 100):

```html
<p class="mission-text">
    Your custom mission statement here...
</p>
```

### Update Schedule

Edit the schedule section in `index.html` (around line 280):

```html
<h3>Your Meeting Day</h3>
<span class="time-value">YOUR-START-TIME</span>
<span class="time-value">YOUR-END-TIME</span>
```

## 📧 Setting Up Contact Form

The contact form uses **Formspree** (free tier available). To make it work:

### Option 1: Formspree (Recommended)

1. Go to [formspree.io](https://formspree.io)
2. Sign up with your email
3. Create a new form
4. Copy your form ID (looks like: `xrgjwkpy`)
5. Update `index.html`:

```html
<form action="https://formspree.io/f/YOUR-FORM-ID" method="POST" class="contact-form" id="contactForm">
```

### Option 2: Email Directly

Replace the form with a simple mailto link:

```html
<a href="mailto:your-email@gmail.com" class="btn btn-primary">
    <i class="fas fa-envelope"></i> Send Email
</a>
```

## 🌐 Deployment

### GitHub Pages (Free)

1. Push this repository to GitHub
2. Go to **Settings** → **Pages**
3. Select **Deploy from a branch**
4. Choose **main** branch and **/(root)** folder
5. Click **Save**
6. Your site will be live at: `https://your-username.github.io/senay-hilna`

### Netlify (Free)

1. Go to [netlify.com](https://netlify.com)
2. Drag and drop your project folder
3. Your site is instantly live!

### Vercel (Free)

1. Go to [vercel.com](https://vercel.com)
2. Import your GitHub repository
3. Deploy with one click
